DATASET INFORMATION

1. CIC-IDS2017
Official link: https://www.unb.ca/cic/datasets/ids-2017.html
Description: A labelled network intrusion detection dataset containing benign traffic and multiple common attack types. It includes traffic captured over several days and is commonly used to evaluate intrusion detection models.

2. CSE-CIC-IDS2018
Official link: https://www.unb.ca/cic/datasets/ids-2018.html
Description: A network traffic dataset containing benign activity and different attack scenarios, including denial-of-service and distributed denial-of-service attacks. It can be used to evaluate how detection models perform on traffic collected in a different environment.

3. CIC-DDoS2019
Official link: https://www.unb.ca/cic/datasets/ddos-2019.html
Description: A dataset developed for DDoS detection research. It contains benign traffic and multiple DDoS attack types, with labelled network traffic and flow-based data for machine-learning experiments.

4. CIC IoT-DIAD 2024
Official link: https://www.unb.ca/cic/datasets/iot-diad-2024.html
Description: An Internet of Things dataset designed for device identification and anomaly detection. It includes IoT network traffic and attack scenarios, including DDoS-related activity, and may require feature and label alignment before comparison with traditional IDS datasets.

Note: These links lead to the official dataset pages, where dataset descriptions and available downloads can be found.
